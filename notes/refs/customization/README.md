# In-game Customization references (2026-10-16)

Screenshots from Fantasy Life i Base Camp **Customization** (Hagram float view). Target look for Stolen Hours Village outdoor.

## Visual ground truth
- **Grass:** saturated green carpet, soft stipple — not muddy PBR.
- **Cliffs:** layered brown/tan sedimentary bands; **rounded grass overhang lips** (not sharp boxes).
- **Water:** deep blue with **white foam** at shorelines; canals/ponds cut into grass.
- **Houses:** fully textured thatched / patterned walls (never flat white).
- **Guild / plazas:** blue patterned tile courtyards under structures.
- **Cursor:** glowing **cyan tile** + floating gem/gear marker.
- **Occupied tiles:** dark **X** marks on grass under placeables.
- **Debris:** textured rubble; **red** multi-tile grid when invalid / selected for move.
- **Camera:** high oblique float; optional giant mossy hands are in-game chrome (editor can omit).
